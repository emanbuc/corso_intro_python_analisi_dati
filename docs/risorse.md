# Risorse e bibliografia

## Per approfondire

- [Tutorial ufficiale di Python](https://docs.python.org/3/tutorial/) — il riferimento per la
  sintassi di base vista nella lezione 1 (tipi, strutture dati, controllo di flusso, funzioni).
- [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) — panoramica rapida
  delle operazioni su DataFrame delle lezioni 2 e 3; utile come ripasso.
- [Python for Data Analysis, 3ª edizione](https://wesmckinney.com/book/) di Wes McKinney, consultabile
  online — il testo di riferimento per NumPy e pandas, scritto dall'autore di pandas.
- [Tutorial di seaborn](https://seaborn.pydata.org/tutorial.html) — galleria ragionata dei tipi di
  grafico usati nella lezione 3.

## Strumenti

- [Google Colab](https://colab.research.google.com/) — notebook nel browser, nessuna installazione;
  è l'ambiente usato in aula.
- [JupyterLab](https://jupyter.org/) — l'alternativa in locale, per chi preferisce lavorare sul proprio computer.
- Librerie: [pandas](https://pandas.pydata.org/docs/), [NumPy](https://numpy.org/doc/stable/),
  [Matplotlib](https://matplotlib.org/stable/), [seaborn](https://seaborn.pydata.org/) — documentazione ufficiale.

## Dati aperti

- [Open Data del Comune di Milano](https://dati.comune.milano.it/) — fonte del dataset
  dell'[esempio realistico](esempi/turismo-milano.md) e del [mini-progetto](esercitazioni/04-mini-progetto.md).
- [dati.gov.it](https://www.dati.gov.it/) — catalogo nazionale dei dati aperti della pubblica amministrazione.
- [ISTAT](https://www.istat.it/) — statistiche ufficiali italiane.

Fonti e licenze dei file usati nel corso sono nella pagina [Dataset](dati.md).
